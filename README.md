# Events Page (HTML Practice)

A beginner HTML project built while following a web development tutorial
by the [EMC YouTube channel]https://www.youtube.com/@ErrorMakesClever.

## What it is
A simple "Upcoming Events" page that shows registered events with
images, details and contact information.

## What I practiced
- HTML page structure (head and body)
- Headings and paragraphs
- Images with alt text
- Links
- Horizontal lines and centered content
- Adding a favicon and emojis

## Note
This is a practice project and only uses HTML, with no CSS.
The contact details on the page are dummy placeholders.
